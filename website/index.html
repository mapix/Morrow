哪些 Mac 可以运行 Morrow？

Morrow 需要 Apple Silicon 和 macOS 26 或更高版本。当前下载的具体要求请查看公开版本说明。

可以继续用现在的邮箱吗？

可以。支持 IMAP/SMTP 邮箱、Gmail OAuth 和 POP3 账户。多个账户可以放在同一个工作台中。

必须使用云端模型吗？

你可以选择本机模型、兼容的 HTTPS 模型服务，或使用原生 ChatGPT 登录。具体能力取决于所选模型和配置。

我的数据会去哪里？

邮件和工作空间数据默认保留在 Mac。所配置的远程模型会收到任务内容；可选 iCloud 可同步工作空间。邮件外部图片默认加载，可以关闭。持有你的 MCP 令牌的客户端可读取服务开放的数据。

Morrow 会自动发邮件吗？

自动响应器的发送方式由你设置。先明确范围并试跑，自动发送需要在应用中显式授权。网页上的演示使用虚构内容，不会发送任何邮件。

在哪里看源码或反馈问题？

Morrow 采用 Apache 2.0 开源协议。查看 GitHub 仓库 / 反馈问题
